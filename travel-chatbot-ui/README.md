# 🌍 Travel Chatbot UI

React-based frontend for **India Travel & Festival Chatbot**.

## Features
- Responsive Navbar + Footer
- Register / Login
- Chatbot (protected)
- Travel Planner
- Festival recommendations
- About / Contact / Profile

## Run Locally
```bash
npx create-react-app travel-chatbot-ui
cd travel-chatbot-ui
# replace src/ and public/ with provided files
npm install
npm start
